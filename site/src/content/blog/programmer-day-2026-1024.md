今天就是 10 月 24 日，程序员节。

1024，是 2 的 10 次方，是 1KB 的字节数，是二进制世界里一个朴素又特别的数字。它不像 520 那样直白，也不像 618 那样热闹，但对程序员来说，1024 自带一种默契：你懂，我也懂。

程序员节不是一个法定假日。它更像是行业内部的一次相视一笑：今天不祝你“需求一次过”，也不祝你“上线零回滚”，只祝你写的每一行代码，都对得起自己熬过的夜；祝你每次 `git push` 之后，都能安心合上电脑。

在外人眼里，程序员的工作可能是“修电脑的”“写代码的”“加班的”。但真正坐在屏幕前的人知道，那是一遍遍拆解问题、一次次推翻重来、一行行把模糊的想法变成可运行的系统。是凌晨还在看日志，是周末还在想那个偶现的 bug，是嘴上说着“这需求不合理”，手上还是把方案改到了第三版。

1024 这个数字，也像程序员群体的某种性格：不张扬，但稳定；不浪漫，但可靠。它藏在内存里，藏在文件大小里，藏在每一次数据传递的底层。就像程序员的工作，常常不被看见，却支撑着很多被看见的东西。

今天，如果你身边有程序员，可以不用送花，也不用刻意庆祝。一句“今天程序员节啊，早点下班”就很够意思。如果对方正在改 bug，递杯咖啡；如果对方刚上线，说句辛苦；如果对方说“我没事”，那可能是真的在排查问题。

当然，也要对每一位程序员说：代码写不完，需求接不完，但身体是自己的。1024 不只是工作量的单位，也可以是提醒自己休息的刻度。该提交提交，该合盖合盖。世界不会因为你早睡一晚就宕机，但你会因为多睡一小时而更像一个正常人。

今天就是程序员节。愿你的构建一次通过，愿你的日志没有红色，愿你的线上风平浪静，愿你的生活不止有 `TODO`，还有 `DONE` 和 `LIVE`。

1024，节日快乐。

## 后记：1024 连当个标签都不太安分

这篇文章发布的时候，还出了个小插曲。

我在 frontmatter 里写标签，顺手写了：

```yaml
tags:
- 程序员节
- 1024
- 技术文化
```

结果 Astro 直接甩脸：

```text
[InvalidContentEntryDataError] blog → programmer-day-2026-1024 data does not match collection schema.
tags.1: Expected type `"string"`, received `"number"`
```

翻译一下就是：`tags` 数组里第二项，我期望它是字符串，你却给了我一个数字。

原因也很程序员：YAML 看到裸写的 `1024`，很自然地把它解析成了整数。而内容集合的 schema 里写的是 `z.array(z.string())`，标签必须是字符串，于是校验失败。`程序员节` 和 `技术文化` 都没事，因为它们本来就长得不像数字，只有 `1024` 被 YAML “好心”转成了 number。

改法很简单，加个引号：

```yaml
tags:
- 程序员节
- "1024"
- 技术文化
```

保存，Astro 重新同步内容，错误消失。

这件事本身很小，但放在程序员节这天，莫名有点应景。1024 这个数字，平时藏在内存里、文件大小里、权限里，到了 frontmatter 里，它还是不肯老老实实当个字符串。行吧，是它的风格。

当然，也可以从 schema 层面兼容，比如：

```ts
tags: z.array(z.coerce.string()).default([])
```

或者：

```ts
tags: z.array(z.union([z.string(), z.number()])).default([])
```

但更推荐的做法还是统一数据格式：标签就是标签，全部写成字符串。别让 `"1024"` 和 `1024` 在后面的过滤、渲染、统计里混着出现，省得哪天又冒出一个“为什么这个标签点不动”的问题。

所以，1024 节日快乐。愿你的构建一次通过，愿你的 schema 不报类型错误，愿你的标签都是字符串——包括 1024。
