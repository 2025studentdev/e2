环境安装好、PyCharm 配置完成之后，下一步就是掌握 Python 的标准语法。这里说的“标准语法”，既包括 Python 解释器认可的语法规则，也包括社区广泛遵循的 PEP 8 代码风格。语法决定程序能不能运行，风格决定代码能不能被别人轻松读懂。对初学者来说，两者都值得从一开始就重视。

Python 的语法有一个很鲜明的特点：它用缩进来表示代码块，而不是用大括号。这意味着一行代码属于哪个分支、哪个循环、哪个函数，主要看它的缩进层级。标准做法是每级缩进使用四个空格，不要混用空格和制表符。冒号通常表示一个代码块的开始，例如 `if`、`for`、`while`、`def`、`class` 后面的冒号，下一行必须缩进。

```python
score = 85

if score >= 60:
    print("及格")
else:
    print("不及格")
```

这段代码里，两个 `print` 分别属于 `if` 和 `else` 分支，靠缩进区分。如果缩进不一致，Python 会直接报错。也正因为缩进参与语法，Python 代码天然比较整齐，但新手要特别注意不要在同一代码块里混用不同数量的空格。

## 变量、类型与表达式

Python 是动态类型语言，变量不需要提前声明类型。赋值语句会把名字绑定到一个对象上，类型由对象决定。

```python
name = "Alice"
age = 20
height = 1.68
is_student = True
nothing = None
```

常见内置类型包括整数 `int`、浮点数 `float`、字符串 `str`、布尔值 `bool`、空值 `None`，以及后面会讲到的列表、元组、字典和集合。变量名区分大小写，只能由字母、数字和下划线组成，不能以数字开头。标准风格推荐使用小写字母加下划线的 `snake_case`，例如 `user_name`、`total_count`。常量通常用全大写，例如 `MAX_SIZE`。

表达式由变量、字面量和运算符组成。算术运算符有 `+`、`-`、`*`、`/`、`//`、`%`、`**`，分别对应加减乘、真除法、整除、取余和幂运算。比较运算符包括 `==`、`!=`、`>`、`<`、`>=`、`<=`。逻辑运算符是 `and`、`or`、`not`。成员判断用 `in`，身份判断用 `is`。这里要特别注意：判断两个值是否相等用 `==`，判断两个名字是否指向同一个对象才用 `is`。新手常把 `is` 当成 `==` 使用，这是不推荐的。

```python
a = 10
b = 3

print(a / b)    # 3.333...
print(a // b)   # 3
print(a % b)    # 1
print(a ** b)   # 1000
```

## 字符串与常用数据结构

字符串可以用单引号或双引号表示，三引号可以表示多行字符串。字符串是不可变对象，切片会返回新字符串。格式化字符串推荐使用 f-string。

```python
name = "Alice"
age = 20

message = f"{name} is {age} years old."
print(message)
print(name[0])
print(name[1:4])
```

列表 `list` 是有序可变序列，用方括号表示；元组 `tuple` 是有序不可变序列，用圆括号表示；字典 `dict` 存储键值对，用花括号表示；集合 `set` 存储不重复元素，也用花括号表示。列表适合保存需要增删改查的一组数据，字典适合按名字快速查找值。

```python
scores = [85, 92, 78]
scores.append(90)
print(scores[0])

student = {"name": "Alice", "age": 20}
print(student["name"])

point = (3, 5)
unique_numbers = {1, 2, 2, 3}
print(unique_numbers)
```

列表和字典是入门阶段使用频率最高的两种结构。要熟悉列表的索引、切片、`append`、`remove`、`len`，以及字典的按键取值、`get`、`keys`、`values`、`items`。遍历字典时，`items()` 可以同时拿到键和值。

## 条件判断与循环

条件判断使用 `if`、`elif`、`else`。Python 没有 `switch` 语句的旧式写法，多分支通常用 `if-elif-else` 表达。条件表达式可以直接放在 `if` 后面，只要结果能被解释为真或假即可。

```python
score = 85

if score >= 90:
    level = "优秀"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"

print(level)
```

循环主要有 `for` 和 `while`。`for` 用来遍历可迭代对象，例如列表、字符串、字典、`range()` 生成的数字序列。`while` 在条件为真时反复执行。`break` 用于提前结束循环，`continue` 用于跳过本次进入下一次。Python 的循环还可以带 `else` 子句，当循环正常结束、没有被 `break` 打断时执行，这个特性初学阶段了解即可。

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)

count = 0
while count < 3:
    print("count:", count)
    count += 1
```

## 函数

函数用 `def` 定义，函数名同样推荐 `snake_case`。函数可以接收参数、返回值。参数可以有默认值，调用时可以使用位置参数或关键字参数。`*args` 接收任意数量的位置参数，`**kwargs` 接收任意数量的关键字参数。函数体第一行可以写文档字符串，用三引号说明函数用途。

```python
def greet(name, greeting="Hello"):
    """返回一句问候语。"""
    return f"{greeting}, {name}!"

print(greet("Alice"))
print(greet("Bob", greeting="Hi"))
```

函数内部赋值的变量默认是局部变量，只在函数内有效。如果要在函数内修改全局变量，需要显式使用 `global`，但入门阶段应尽量通过参数和返回值传递数据，减少对全局变量的依赖。另一个常见陷阱是使用可变对象作为默认参数，例如 `def add(item, items=[])`，默认列表会在多次调用之间共享。需要默认空列表时，标准写法是用 `None` 作为默认值，在函数体内再创建列表。

## 异常处理

程序运行中可能遇到错误，例如文件不存在、除数为零、输入无法转换。异常处理使用 `try`、`except`、`else`、`finally`。`try` 块放可能出错的代码，`except` 捕获指定异常，`else` 在未发生异常时执行，`finally` 无论是否异常都会执行。

```python
try:
    number = int(input("请输入一个整数："))
    result = 10 / number
except ValueError:
    print("输入的不是整数")
except ZeroDivisionError:
    print("不能除以零")
else:
    print("结果是", result)
finally:
    print("程序结束")
```

捕获异常时尽量指明具体异常类型，不要用一个裸 `except` 吞掉所有错误。需要主动抛出异常时使用 `raise`。异常处理的目标是让程序在可预期的错误面前有合理反应，而不是掩盖所有问题。

## 模块、导入与程序入口

Python 文件本身就是一个模块。使用 `import` 可以导入标准库、第三方库或自己写的模块。常见写法有 `import math`、`from datetime import datetime`。导入语句通常放在文件顶部，标准库、第三方库、本地模块分组书写。

```python
import math
from datetime import datetime

print(math.sqrt(16))
print(datetime.now())
```

当一个 Python 文件既可能被直接运行，也可能被其他文件导入时，标准写法是把直接运行的代码放在 `if __name__ == "__main__":` 下面。这样被导入时不会自动执行测试代码，直接运行时才会执行。

```python
def main():
    print("程序开始运行")

if __name__ == "__main__":
    main()
```

## 类的基础语法

面向对象不是入门第一天必须掌握的内容，但标准语法中类的基本写法需要认识。类用 `class` 定义，实例方法第一个参数通常是 `self`，构造方法叫 `__init__`。实例属性在 `__init__` 中赋值，方法通过 `self` 访问属性。

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"我是{self.name}，今年{self.age}岁。"

student = Student("Alice", 20)
print(student.introduce())
```

初学阶段先把函数和数据结构用熟，再逐步理解类。类不是语法学习的起点，而是组织代码的一种方式。

## 文件操作与代码风格

文件读写推荐使用 `with open(...) as ...`，它能自动关闭文件。读取文本文件常用 `read()`、`readlines()` 或直接遍历文件对象，写入用 `write()`。

```python
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("第一行\n第二行\n")

with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

最后要强调代码风格。PEP 8 是 Python 社区广泛遵循的风格指南：每级缩进四个空格；运算符两侧和逗号后面留空格；函数名、变量名用 `snake_case`；类名用 `CamelCase`；常量用全大写；导入语句分组放在文件顶部；避免过长的行。风格不会改变程序运行结果，但会让代码更易读，也更容易在报错时定位问题。

标准语法不是靠一次性背完的。更有效的方式是每学一个语法点，就在 PyCharm 里写一个小例子验证，再把它放进一个小项目里使用。比如用列表和循环做待办清单，用函数封装计算逻辑，用字典保存学生成绩，用 `try-except` 处理用户输入错误。语法是写程序的工具，真正熟悉它，靠的是不断动手写、不断调试、不断回头补。
