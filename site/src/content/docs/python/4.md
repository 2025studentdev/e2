Turtle 是 Python 内置的绘图模块，不需要额外安装，在信息课里用来理解“程序控制图形”非常直观。下面按功能分类整理最常用的命令，每个都附简短说明和关键参数。调用时统一用 `turtle.函数名()` 的形式，前提是已经 `import turtle`。


## 一、导入与基础设置

```python
import turtle
turtle.title("我的画布")        # 设置窗口标题
turtle.setup(800, 600)         # 设置窗口大小（宽, 高）
turtle.bgcolor("lightyellow")  # 设置背景色
turtle.done()                  # 绘图结束后保持窗口不关闭
```

`done()` 放在程序最后，防止画完窗口一闪而过。


## 二、画笔控制（画不画线）

| 命令 | 作用 |
|---|---|
| `turtle.penup()` / `turtle.pu()` / `turtle.up()` | 抬笔，移动时不画线 |
| `turtle.pendown()` / `turtle.pd()` / `turtle.down()` | 落笔，移动时画线 |
| `turtle.pensize(w)` / `turtle.width(w)` | 设置画笔粗细，单位像素 |
| `turtle.isdown()` | 画笔落下返回 `True`，抬起返回 `False` |

`penup` / `pendown` 是最常用的组合：抬笔跳到新位置，落笔继续画，用来画不连续的图形。


## 三、移动与转向

| 命令 | 作用 |
|---|---|
| `turtle.forward(d)` / `turtle.fd(d)` | 沿当前朝向前进 d 像素 |
| `turtle.backward(d)` / `turtle.bk(d)` | 沿当前朝向后退 d 像素，朝向不变 |
| `turtle.right(θ)` / `turtle.rt(θ)` | 顺时针旋转 θ 度 |
| `turtle.left(θ)` / `turtle.lt(θ)` | 逆时针旋转 θ 度 |
| `turtle.goto(x, y)` | 直线移动到坐标 (x, y) |
| `turtle.home()` | 回到原点 (0,0)，朝向东方（x 轴正方向） |
| `turtle.setheading(θ)` | 把朝向设为绝对角度 θ |

`forward` 和 `right` / `left` 是最核心的三个命令，画任何折线图形都离不开它们。`goto` 适合配合 `penup` 使用，跳到指定坐标再继续。


## 四、画圆与圆弧

```python
turtle.circle(radius)
turtle.circle(radius, extent)
turtle.circle(radius, extent, steps)
```

`radius` 是半径；正数时圆心在画笔左侧，负数时圆心在右侧。`extent` 是画多少度，省略则画完整圆（如 `circle(100, 180)` 画半圆）。`steps` 用于画正多边形，例如 `circle(100, steps=4)` 画一个正方形。


## 五、填充颜色

填充需要三步：`begin_fill()` → 画封闭图形 → `end_fill()`。

```python
turtle.fillcolor("yellow")
turtle.begin_fill()
for _ in range(4):
    turtle.forward(100)
    turtle.right(90)
turtle.end_fill()
```

`fillcolor("颜色")` 设置填充色，`begin_fill()` 标记开始，`end_fill()` 真正执行填充。`turtle.color("red", "yellow")` 可以同时设置画笔色和填充色。


## 六、颜色设置

| 命令 | 作用 |
|---|---|
| `turtle.pencolor("red")` | 设置画笔颜色 |
| `turtle.fillcolor("blue")` | 设置填充颜色 |
| `turtle.color("red", "yellow")` | 同时设画笔色和填充色 |
| `turtle.pencolor((255, 0, 0))` | 用 RGB 三元组设色 |

RGB 每个分量范围是 0–255（默认模式）。用 RGB 前如果颜色异常，可以先用 `turtle.colormode(255)` 确认模式。


## 七、速度与显示

```python
turtle.speed(0)      # 0 最快，无动画
turtle.speed(10)     # 1–10，数字越大越快
turtle.speed("fastest")  # 也可用字符串
```

`speed` 默认是 3（较慢）。调试大图形时用 `speed(0)` 可以瞬间画完。

`turtle.hideturtle()` 隐藏海龟箭头，`turtle.showturtle()` 重新显示，让画面更干净。


## 八、获取状态（查询用）

| 命令 | 返回 |
|---|---|
| `turtle.pos()` | 当前位置 `(x, y)` |
| `turtle.xcor()` | 当前 x 坐标 |
| `turtle.ycor()` | 当前 y 坐标 |
| `turtle.heading()` | 当前朝向角度 |

这些命令主要用来做判断，例如判断海龟是否回到了起点附近。


## 九、写文字

```python
turtle.write("Hello", align="center", font=("Arial", 16, "normal"))
```

在当前位置写文字。`align` 可选 `"left"` / `"center"` / `"right"`；`font` 是三元组 `(字体名, 字号, 样式)`。


## 十、清屏与重置

| 命令 | 作用 |
|---|---|
| `turtle.clear()` | 清空画面，海龟位置和状态不变 |
| `turtle.reset()` | 清空画面，海龟回到原点，恢复初始状态 |
| `turtle.clearscreen()` | 清空整个窗口并重置所有设置 |

`clear` 适合“擦掉重画”，`reset` 适合“完全重来”。


## 十一、简单事件（了解即可）

如果想让画布响应鼠标或键盘：

```python
turtle.onclick(函数名)        # 点击画布时调用函数
turtle.onkey(函数名, "Up")    # 按上箭头时调用
turtle.listen()               # 开始监听键盘
```

事件处理在信息课基础练习中用得不多，知道 `onclick` 和 `onkey` 的存在即可。


## 一个最小的完整示例

```python
import turtle

turtle.speed(0)
turtle.bgcolor("lightyellow")
turtle.pensize(3)

turtle.fillcolor("orange")
turtle.begin_fill()
for _ in range(4):
    turtle.forward(100)
    turtle.right(90)
turtle.end_fill()

turtle.penup()
turtle.goto(-150, 80)
turtle.pendown()
turtle.pencolor("blue")
turtle.write("正方形", font=("Arial", 16, "bold"))

turtle.done()
```


## 信息课练习时容易踩的坑

**忘记 `penup` 就 `goto`**：海龟会拖着一条线移动，画出多余的线段。

**填充没有生效**：检查 `begin_fill()` 和 `end_fill()` 是否配对，以及填充色是否在开始填充前设置。

**`circle` 的正负号搞反**：正半径画出的圆在画笔左侧，负半径在右侧，画组合图形时方向会相反。

**`speed` 数值含义记反**：`0` 是最快，`1` 最慢，`10` 较快，不是数字越小越慢。

这份汇总可以当作速查表用。练习时建议先只用到 `forward`、`right`、`penup`、`pendown`、`circle` 这几个命令，把三角形、正方形、五角星画出来，再逐步加入颜色和填充。
