学会写函数，是 Python 入门的一个关键节点。前面学的变量、条件判断、循环，都是在“写一段会执行的代码”；而函数让你把一段代码**打包起来，起个名字，以后反复调用**。这一篇只讲一件事：从零开始，自己写一个能用的函数。

## 一、函数到底是什么

函数就是一段有名字的代码块。你定义一次，之后可以调用任意多次。定义用 `def` 关键字，结构如下：

```python
def 函数名():
    函数体
```

函数名后面必须有一对圆括号，最后有一个冒号。函数体要缩进，通常四个空格。定义函数只是“告诉 Python 有这么个东西”，**不会执行里面的代码**。只有调用时才会执行。

```python
def say_hello():
    print("你好")

say_hello()
say_hello()
```

运行结果会打印两次“你好”。`def say_hello():` 是定义，`say_hello()` 是调用。注意调用时没有 `def`，也没有冒号。

## 二、给函数加参数

上面的函数每次都说“你好”，太死板。参数让函数可以接收外部传进来的数据。

```python
def greet(name):
    print(f"你好，{name}")

greet("小明")
greet("小红")
```

`name` 是参数名，调用时传入的“小明”“小红”是实际参数。函数内部把 `name` 当成一个普通变量使用。可以有多个参数，用逗号隔开：

```python
def introduce(name, age):
    print(f"我叫{name}，今年{age}岁")

introduce("小明", 18)
```

调用时参数顺序要和定义时一致。`introduce(18, "小明")` 虽然语法不报错，但输出会变成“我叫18，今年小明岁”，逻辑就错了。

## 三、返回值：让函数把结果交出来

很多函数不只是打印，而是**算出一个结果交给调用者**。用 `return` 返回。

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
```

`return` 把 `a + b` 的结果交出去，`result` 接收到 8。`return` 后面的代码不会再执行：

```python
def test():
    return 1
    print("这行不会执行")

print(test())
```

如果函数没有写 `return`，或者只写了 `return` 没有值，函数返回 `None`。`None` 表示“没有值”，不是 0，也不是空字符串。

```python
def say_hi():
    print("hi")

value = say_hi()
print(value)   # None
```

一个函数可以返回多个值，实际上是返回一个元组：

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([3, 1, 4, 1, 5])
print(low, high)
```

## 四、默认参数

有些参数经常用同一个值，可以给它设默认值。调用时不传就用默认值，传了就覆盖。

```python
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}")

greet("小明")
greet("小明", "早上好")
```

默认参数必须放在没有默认值的参数后面。`def greet(greeting="你好", name)` 是语法错误。

## 五、函数里的变量是局部的

函数内部赋值的变量，默认只在函数内部有效，函数外面访问不到。

```python
def calculate():
    result = 10 + 20
    print(result)

calculate()
print(result)   # 报错，result 在函数外不存在
```

这叫局部变量。函数内部的变量和外部互不干扰，这是好事，能避免名字冲突。如果确实需要在函数内修改外部变量，要用 `global`，但入门阶段尽量通过参数传入、通过 `return` 传出，少用 `global`。

## 六、一个稍微完整的小例子

把上面这些组合起来，写一个判断成绩等级的函数：

```python
def get_level(score):
    if score >= 90:
        return "优秀"
    elif score >= 60:
        return "及格"
    else:
        return "不及格"

print(get_level(95))
print(get_level(72))
print(get_level(45))
```

这个函数接收一个分数，返回等级字符串。调用三次，得到三个结果。函数内部用了条件判断，外部完全不用关心判断逻辑，只关心“传分数、拿等级”。

再写一个带默认参数、返回值的函数：

```python
def repeat_text(text, times=3):
    return text * times

print(repeat_text("哈"))
print(repeat_text("哈", 5))
```

## 七、写函数时常见的错误

**忘记调用**：只写了 `def say_hello():`，没有写 `say_hello()`，程序什么也不输出。

**缩进不一致**：函数体没有缩进，或者混用空格和 Tab，会报 `IndentationError`。

**参数数量对不上**：定义了两个参数，调用时只传一个，会报 `TypeError`。

**把 `return` 写成 `print`**：函数里只打印不返回，外面拿到的是 `None`。需要结果时用 `return`，需要展示时用 `print`，两者目的不同。

**默认参数用可变对象**：`def add(item, items=[])` 这种写法，默认列表会在多次调用之间共享，容易出 bug。需要空列表时写成 `def add(item, items=None)`，函数体内再判断。

## 八、练习建议

不要一上来就写复杂函数。按这个顺序练：

1. 写一个无参数、无返回值的函数，只打印一句话，调用两次。
2. 写一个接收一个参数、打印信息的函数。
3. 写一个接收两个数字、返回和的函数，把结果赋给变量再打印。
4. 写一个带默认参数的问候函数，分别用默认值和自定义值调用。
5. 写一个接收列表、返回列表中偶数的函数，用循环实现。
6. 写一个判断闰年的函数，返回 `True` 或 `False`。

每个练习控制在十行左右，写完运行，看输出对不对，再故意改错参数看看报什么错。函数是后面所有内容的基础，这个小坎迈稳了，再往下走会顺很多。
