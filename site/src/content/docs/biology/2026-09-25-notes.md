# 蛋白质与核酸（DNA、RNA）超详细梳理

> 蛋白质是生命活动的主要承担者，核酸是遗传信息的携带者。  
> 本文按“基本知识点 → 高阶考点 → 易错点 → 典型例题”的顺序，把高一生物中蛋白质、DNA、RNA相关内容尽量讲全、讲细。

---

## 总览：蛋白质与核酸对比

| 项目 | 蛋白质 | 核酸 |
|---|---|---|
| 元素组成 | 主要含 C、H、O、N，很多含 S，有的含 Fe、P 等 | C、H、O、N、P |
| 基本单位 | 氨基酸 | 核苷酸 |
| 单体种类 | 约20种（高中常记20种） | 8种：4种脱氧核苷酸 + 4种核糖核苷酸 |
| 连接键 | 肽键（`-CO-NH-`） | 磷酸二酯键 |
| 主要功能 | 催化、运输、调节、免疫、结构、运动等 | 储存、传递、表达遗传信息 |
| 合成场所 | 核糖体 | DNA复制、转录主要在细胞核；RNA翻译在核糖体 |
| 检测试剂 | 双缩脲试剂 → 紫色 | 甲基绿、吡罗红 → DNA绿、RNA红 |

# 第一部分 蛋白质

## 一、基本知识点

### 1. 氨基酸——蛋白质的基本单位

组成蛋白质的氨基酸约有20种。其结构通式可写成：

```text
        R
        |
H2N — C — COOH
        |
        H
```

即：`H2N-CH(R)-COOH`

中心碳原子至少连接：
- 一个氨基：`-NH2`
- 一个羧基：`-COOH`
- 一个氢原子：`-H`
- 一个侧链基团：`-R`

**判断某物质是否为组成蛋白质的氨基酸的关键：**
1. 至少有一个氨基和一个羧基；
2. 氨基和羧基要连在同一个碳原子上；
3. R基可以不同，R基中也可能含有氨基、羧基、S等。

### 2. 脱水缩合

一个氨基酸的羧基与另一个氨基酸的氨基反应，脱去一分子水，形成肽键。

反应本质：
- 氨基脱去 `-H`；
- 羧基脱去 `-OH`；
- 脱去的水分子是 `H2O`。

所以：
- 水中的 H 来自氨基和羧基；
- 水中的 O 来自羧基。

形成的化学键叫肽键：

```text
-CO-NH-
```

由两个氨基酸缩合形成二肽，三个形成三肽，多个形成多肽。多肽通常呈链状，叫肽链。

### 3. 蛋白质的结构层次

| 层次 | 含义 |
|---|---|
| 一级结构 | 氨基酸的排列顺序 |
| 二级结构 | 肽链局部折叠，如α螺旋、β折叠 |
| 三级结构 | 整条肽链进一步盘曲折叠形成空间结构 |
| 四级结构 | 多条肽链聚集形成更复杂的蛋白质 |

高一阶段常简化为：  
**氨基酸 → 多肽 → 蛋白质**

### 4. 蛋白质多样性的原因

1. 氨基酸种类不同；
2. 氨基酸数目不同；
3. 氨基酸排列顺序不同；
4. 肽链的空间结构不同。

根本原因：基因不同，遗传信息不同。

### 5. 蛋白质的功能

| 功能 | 举例 |
|---|---|
| 催化 | 绝大多数酶是蛋白质 |
| 运输 | 血红蛋白运输氧气 |
| 调节 | 胰岛素调节血糖 |
| 免疫 | 抗体 |
| 结构 | 肌肉蛋白、胶原蛋白 |
| 运动 | 肌动蛋白、肌球蛋白 |
| 识别 | 细胞膜上的糖蛋白 |

## 二、蛋白质高阶考点与计算

### 1. 链状多肽计算公式

设：
- 氨基酸数为 `m`
- 肽链数为 `n`
- 肽键数为 `x`
- 脱去水分子数为 `y`

则：

```text
肽键数 = 脱水数 = 氨基酸数 - 肽链数
x = y = m - n
```

游离氨基数至少为：

```text
肽链数 + R基上的氨基数
```

游离羧基数至少为：

```text
肽链数 + R基上的羧基数
```

### 2. 环状肽计算

若多肽首尾相连形成环状：

```text
肽键数 = 脱水数 = 氨基酸数
```

游离氨基、游离羧基一般只来自R基，至少为0。

### 3. N、O原子数计算

对于链状多肽：

```text
N原子数 = 氨基酸数 + R基上的N原子数
O原子数 = 氨基酸数 + 肽链数 + R基上的O原子数
```

原因：
- 每个氨基酸至少含1个N；
- 脱水缩合不脱去N；
- 每个氨基酸至少含2个O，每形成一个肽键脱去1个O，所以主链O数为 `2m - (m-n) = m+n`。

### 4. 蛋白质分子量计算

设氨基酸平均分子量为 `a`，二硫键数为 `S`。

链状蛋白质：

```text
蛋白质分子量 = a × m - 18 × (m - n) - 2 × S
```

环状蛋白质：

```text
蛋白质分子量 = a × m - 18 × m - 2 × S
```

说明：
- 每形成一个肽键脱去1分子水，减少18；
- 每形成一个二硫键 `-S-S-`，脱去2个H，减少2。

### 5. 蛋白质水解计算

- 多肽初步水解：断裂肽键，形成较短肽链；
- 彻底水解：形成氨基酸；
- 需要的水分子数等于断裂的肽键数。

若一个链状多肽有 `m` 个氨基酸、`n` 条肽链，则彻底水解需要：

```text
m - n 个水分子
```

## 三、蛋白质易错点

1. **氨基酸判断易错**  
   不是含氨基和羧基就是氨基酸，必须至少有一个氨基和一个羧基连在同一个碳原子上。

2. **脱水缩合中水的来源易错**  
   水中的 H 来自氨基和羧基，O 来自羧基。

3. **肽键写法易错**  
   肽键是 `-CO-NH-`，不是 `-COOH`，也不是 `-NH2`。

4. **“至少”与“最多”易错**  
   一条肽链至少含1个游离氨基和1个游离羧基，分别位于两端；R基上还可能含有。

5. **环状肽易错**  
   环状肽脱水数等于氨基酸数，不是氨基酸数减肽链数。

6. **二硫键易错**  
   二硫键不是肽键，由两个 `-SH` 脱去2个H形成，计算分子量时要减去2。

7. **变性、盐析、水解易错**
    - 变性：空间结构破坏，肽键不断，仍可与双缩脲试剂呈紫色；
    - 盐析：可逆，蛋白质结构未破坏；
    - 水解：肽键断裂，需要水。

8. **双缩脲试剂易错**  
   双缩脲试剂检测的是肽键，与蛋白质或多肽呈紫色，与氨基酸一般不反应。使用时先加A液，再加B液，不需水浴加热。

## 四、蛋白质典型例题

**例1：** 某链状多肽由100个氨基酸构成，含2条肽链，R基上有5个氨基、3个羧基，平均氨基酸分子量为128，含2个二硫键。求肽键数、脱水数、游离氨基数、游离羧基数、分子量。

解析：

```text
肽键数 = 脱水数 = 100 - 2 = 98
游离氨基数 = 2 + 5 = 7
游离羧基数 = 2 + 3 = 5
分子量 = 128×100 - 18×98 - 2×2
       = 12800 - 1764 - 4
       = 11032
```

# 第二部分 核酸——DNA和RNA

## 一、基本知识点

### 1. 元素组成与基本单位

核酸的元素组成：**C、H、O、N、P**。

核酸的基本单位是核苷酸。一个核苷酸由三部分组成：

```text
磷酸 + 五碳糖 + 含氮碱基
```

核苷酸之间通过**磷酸二酯键**连接。

### 2. 核苷酸种类

| 核酸 | 五碳糖 | 基本单位 | 碱基 | 种类 |
|---|---|---|---|---|
| DNA | 脱氧核糖 | 脱氧核糖核苷酸 | A、T、G、C | 4种 |
| RNA | 核糖 | 核糖核苷酸 | A、U、G、C | 4种 |

细胞中核酸有DNA和RNA，所以核苷酸共有 **8种**。  
病毒只含一种核酸，所以核苷酸只有 **4种**。

### 3. DNA与RNA比较

| 项目 | DNA | RNA |
|---|---|---|
| 中文名 | 脱氧核糖核酸 | 核糖核酸 |
| 五碳糖 | 脱氧核糖 | 核糖 |
| 特有碱基 | T 胸腺嘧啶 | U 尿嘧啶 |
| 共有碱基 | A、G、C | A、G、C |
| 基本单位 | 脱氧核苷酸 | 核糖核苷酸 |
| 链数 | 通常双链 | 通常单链 |
| 主要分布 | 细胞核、线粒体、叶绿体；原核拟核、质粒 | 细胞质、细胞核 |
| 功能 | 主要遗传物质 | 传递遗传信息、参与翻译、少数催化 |
| 染色 | 甲基绿 → 绿色 | 吡罗红 → 红色 |

### 4. DNA的结构

DNA通常为双螺旋结构：
- 两条链反向平行；
- 磷酸和脱氧核糖交替排列在外侧；
- 碱基排列在内侧；
- 碱基互补配对：A 与 T 配对，G 与 C 配对；
- A—T 之间有2个氢键；
- G—C 之间有3个氢键。

### 5. RNA的类型与功能

| 类型 | 功能 |
|---|---|
| mRNA | 信使RNA，携带遗传信息，指导蛋白质合成 |
| tRNA | 转运RNA，运输氨基酸 |
| rRNA | 核糖体RNA，组成核糖体 |

### 6. 分布与遗传物质

- 真核细胞：DNA主要在细胞核，线粒体、叶绿体中也有；RNA主要在细胞质。
- 原核细胞：DNA主要在拟核，质粒中也有；RNA在细胞质。
- 病毒：只含一种核酸，DNA病毒或RNA病毒。
- 细胞生物的遗传物质都是DNA。
- 病毒：DNA病毒的遗传物质是DNA，RNA病毒的遗传物质是RNA。

### 7. 观察DNA和RNA在细胞中的分布

实验原理：
- 甲基绿使DNA呈绿色；
- 吡罗红使RNA呈红色；
- 甲基绿和吡罗红混合染色剂使用。

现象：
- 细胞核呈绿色；
- 细胞质呈红色。

盐酸的作用：
1. 改变细胞膜通透性，加速染色剂进入细胞；
2. 使染色质中的DNA与蛋白质分离，有利于DNA与染色剂结合。

## 二、核酸高阶考点与计算

### 1. 双链DNA碱基计算

双链DNA中：

```text
A = T
G = C
A + G = T + C = 总数的50%
```

即：嘌呤数 = 嘧啶数。

注意：
- 单链DNA中，A不一定等于T，G不一定等于C；
- RNA通常是单链，不能套用 A=U、G=C。

### 2. 单链与双链关系

若DNA一条链中：
```text
A : T : G : C = a : b : c : d
```

则互补链中：
```text
A : T : G : C = b : a : d : c
```

因为：
- 一条链的A与另一条链的T配对；
- 一条链的T与另一条链的A配对；
- 一条链的G与另一条链的C配对；
- 一条链的C与另一条链的G配对。

双链DNA中：

```text
(A + T) / (G + C)
```

在两条单链中与双链中相同。

但：

```text
(A + G) / (T + C)
```

在双链中等于1，在单链中不一定等于1。

### 3. 氢键数计算

双链DNA中：

```text
氢键总数 = 2 × A + 3 × G
         = 2 × T + 3 × C
```

因为：
- A—T 有2个氢键；
- G—C 有3个氢键。

### 4. DNA复制相关计算

若原DNA中有某种碱基 `x` 个，复制 `n` 次：

```text
复制n次后，DNA分子数 = 2^n
需要游离该碱基数 = (2^n - 1) × x
第n次复制需要游离该碱基数 = 2^(n-1) × x
```

### 5. 转录相关计算

DNA转录形成mRNA时：
- 以DNA的一条链为模板；
- mRNA与模板链碱基互补；
- mRNA中的A对应模板链中的T；
- mRNA中的U对应模板链中的A；
- mRNA中的G对应模板链中的C；
- mRNA中的C对应模板链中的G。

因此：

```text
mRNA中A + U = DNA模板链中A + T
mRNA中G + C = DNA模板链中G + C
```

### 6. 核酸水解产物

| 材料 | 初步水解 | 彻底水解 |
|---|---|---|
| DNA | 4种脱氧核苷酸 | 磷酸、脱氧核糖、A、T、G、C |
| RNA | 4种核糖核苷酸 | 磷酸、核糖、A、U、G、C |
| 细胞中全部核酸 | 8种核苷酸 | 磷酸、脱氧核糖、核糖、A、G、C、T、U |
| DNA病毒 | 4种脱氧核苷酸 | 磷酸、脱氧核糖、A、T、G、C |
| RNA病毒 | 4种核糖核苷酸 | 磷酸、核糖、A、U、G、C |

注意：
- 细胞中核苷酸有8种；
- 细胞中碱基有5种：A、G、C、T、U；
- DNA彻底水解产物有6种：磷酸、脱氧核糖、4种碱基；
- RNA彻底水解产物有6种：磷酸、核糖、4种碱基；
- 细胞中全部核酸彻底水解产物有8种：磷酸、脱氧核糖、核糖、5种碱基。

## 三、核酸易错点

1. **DNA和RNA的五碳糖易混**  
   DNA含脱氧核糖，RNA含核糖。

2. **特有碱基易混**  
   DNA特有T，RNA特有U；共有A、G、C。

3. **核苷酸种类易错**  
   细胞中核酸有DNA和RNA，所以核苷酸8种；病毒只有一种核酸，所以核苷酸4种。

4. **碱基种类易错**  
   细胞中碱基5种；DNA病毒碱基4种：A、T、G、C；RNA病毒碱基4种：A、U、G、C。

5. **双链DNA规则不能乱用**  
   A=T、G=C只适用于双链DNA，不适用于单链DNA，也不适用于RNA。

6. **RNA中A不一定等于U**  
   RNA通常单链，没有A=U的必然关系。

7. **水解与氧化分解易混**  
   水解是加水断裂化学键；氧化分解是彻底分解为CO₂、H₂O等。

8. **甲基绿吡罗红易混**  
   甲基绿使DNA呈绿色，吡罗红使RNA呈红色，不是反过来。

9. **遗传物质易错**  
   细胞生物遗传物质是DNA；病毒遗传物质是DNA或RNA。不能说所有生物遗传物质都是DNA。

10. **氢键与磷酸二酯键易混**
- 氢键连接碱基对；
- 磷酸二酯键连接核苷酸；
- DNA解旋破坏氢键，不是破坏磷酸二酯键。

11. **原核与真核易错**  
    原核细胞和真核细胞都含DNA和RNA，遗传物质都是DNA。

## 四、核酸典型例题

**例1：** 某双链DNA中A占30%，求T、G、C的比例。

解析：

```text
A = T = 30%
A + T = 60%
G + C = 40%
G = C = 20%
```

**例2：** DNA一条链中A=40%，T=20%，求互补链中A、T的比例。

解析：

一条链：
```text
A = 40%，T = 20%
```

互补链：
```text
A = 20%，T = 40%
```

因为互补链的A与原来链的T配对，互补链的T与原来链的A配对。

**例3：** 某DNA中有A 100个，复制3次，共需要游离的A多少个？

解析：

```text
复制3次后DNA数 = 2^3 = 8
需要游离A = (8 - 1) × 100 = 700
```

# 第三部分 综合必背与口诀

## 1. 蛋白质必背

```text
氨基酸通式记，氨基羧基同碳连；
脱水缩合肽键成，链状脱水=氨基酸-肽链；
一条肽链两端，至少氨基羧基各一个；
R基若有再加，环状肽链要小心；
二硫键减2，变性盐析要分清。
```

## 2. 核酸必背

```text
DNA脱氧T，RNA核糖U；
双链A=T，G=C要记住；
细胞生物DNA，病毒一种核酸；
核苷酸八种，碱基五种；
初步水解核苷酸，彻底水解磷酸糖碱基。
```

## 3. 高频比较表

| 比较项 | 蛋白质 | DNA | RNA |
|---|---|---|---|
| 单体 | 氨基酸 | 脱氧核苷酸 | 核糖核苷酸 |
| 特征元素 | N，常含S | P | P |
| 特有成分 | 肽键 | 脱氧核糖、T | 核糖、U |
| 主要功能 | 生命活动承担者 | 主要遗传物质 | 传递遗传信息、翻译 |
| 检测 | 双缩脲试剂→紫色 | 甲基绿→绿色 | 吡罗红→红色 |

## 最后提醒

1. 蛋白质部分最容易考计算：肽键数、脱水数、游离氨基/羧基数、N/O原子数、分子量、二硫键、环状肽。
2. 核酸部分最容易考区分：DNA和RNA的五碳糖、碱基、核苷酸种类、分布、水解产物。
3. 遇到“至少”要想肽链数；遇到“环状”要想脱水数等于氨基酸数；遇到“双链DNA”才可用A=T、G=C。
4. 细胞生物遗传物质是DNA，病毒遗传物质是DNA或RNA。
5. 蛋白质变性不断肽键，核酸水解断裂磷酸二酯键或氢键要看具体过程。
