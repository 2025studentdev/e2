# 物质的通性与转化、电解质与电离

## 第一章 酸碱盐的通性与反应规律

### 1. 酸的通性
*   **① 酸 + 指示剂**：使紫色石蕊变红，无色酚酞不变色。
*   **② 酸 + 金属 $\rightarrow$ 盐 + $\text{H}_2\uparrow$**
*   **③ 酸 + 碱 $\rightarrow$ 盐 + 水**（中和反应）
*   **④ 酸 + 碱性氧化物 $\rightarrow$ 盐 + 水**
*   **⑤ 酸 + 盐 $\rightarrow$ 新酸 + 新盐**（需满足复分解反应条件）
    *   实例：$\text{HCl} + \text{CH}_3\text{COONa} \rightarrow \text{NaCl} + \text{CH}_3\text{COOH}$（强酸制弱酸）

### 2. 碱的通性
*   **① 碱 + 指示剂**：使紫色石蕊变蓝，无色酚酞变红。
*   **② 碱 + 酸 $\rightarrow$ 盐 + 水**
*   **③ 碱 + 酸性氧化物 $\rightarrow$ 盐 + 水**
*   **④ 碱 + 盐 $\rightarrow$ 新碱 + 新盐**（反应物需均可溶，生成物有沉淀、气体或水）
    *   实例：$\text{Ca(OH)}_2 + \text{BaCO}_3 \nrightarrow$ （不反应，因为$\text{BaCO}_3$不溶）
    *   实例：$\text{Ca(OH)}_2 + \text{Na}_2\text{CO}_3 \rightarrow \text{CaCO}_3\downarrow + 2\text{NaOH}$
    *   实例：$\text{MgSO}_4 + \text{Ba(OH)}_2 \rightarrow \text{BaSO}_4\downarrow + \text{Mg(OH)}_2\downarrow$
    *   实例：$\text{Fe}_2(\text{SO}_4)_3 + \text{Ba(OH)}_2 \rightarrow \text{BaSO}_4\downarrow + \text{Fe(OH)}_3\downarrow$

### 3. 盐的通性
*   **① 盐 + 酸 $\rightarrow$ 新盐 + 新酸**
*   **② 盐 + 碱 $\rightarrow$ 新盐 + 新碱**
*   **③ 盐 + 盐 $\rightarrow$ 新盐 + 新盐**（反应物均可溶，生成物有沉淀）
*   **④ 盐 + 金属 $\rightarrow$ 新盐 + 新金属**（活动性顺序前换后，钾、钙、钠除外）

### 4. 复分解反应条件
*   反应物条件：必须可溶（酸参与反应时，酸可溶即可）。
*   生成物条件：必须有**沉淀**、**气体**或**水**生成。
*   **常见难溶物记忆口诀**：
    *   钾盐、钠盐、铵盐、硝酸盐个个溶。
    *   盐酸盐不溶氯化银（$\text{AgCl}$）。
    *   硫酸盐不溶钡和铅（$\text{BaSO}_4$、$\text{PbSO}_4$）。
    *   碳酸盐除钾、钠、铵外，大多不溶（如$\text{CaCO}_3$、$\text{BaCO}_3$）。
    *   常见的难溶碱：$\text{Mg(OH)}_2$、$\text{Cu(OH)}_2$、$\text{Al(OH)}_3$、$\text{Fe(OH)}_2$、$\text{Fe(OH)}_3$。

## 第二章 物质间的转化与制备

### 1. 常见转化关系示例
*   **碳链**：$\text{C} \rightarrow \text{CO}_2 \rightarrow \text{H}_2\text{CO}_3 \rightarrow \text{Na}_2\text{CO}_3$
*   **钙链**：$\text{Ca} \rightarrow \text{CaO} \rightarrow \text{Ca(OH)}_2 \rightarrow \text{CaCO}_3$
*   **硫链**：$\text{S} \rightarrow \text{SO}_2 \rightarrow \text{SO}_3 \rightarrow \text{H}_2\text{SO}_4$
*   **氮链**：$\text{N} \rightarrow \text{NO} \rightarrow \text{NO}_2 \rightarrow \text{HNO}_3$
*   **转化特例**：
    *   $\text{MgO} \nrightarrow \text{Mg(OH)}_2$（$\text{MgO}$不溶于水，不能直接与水反应生成碱）。
    *   $\text{S} \nrightarrow \text{SO}_3$（硫在氧气中燃烧只能生成$\text{SO}_2$，不能直接生成$\text{SO}_3$）。
    *   $\text{N} \nrightarrow \text{NO}_2$（氮气与氧气在放电条件下生成$\text{NO}$，不能直接生成$\text{NO}_2$）。

### 2. 酸碱性氧化物与酸碱的关系
*   金属氧化物 + $\text{H}_2\text{O}$ $\rightarrow$ 碱（仅限可溶性碱对应的氧化物，如$\text{Na}_2\text{O}$、$\text{CaO}$等）
*   非金属氧化物 + $\text{H}_2\text{O}$ $\rightarrow$ 酸（仅限可溶性酸对应的氧化物，如$\text{CO}_2$、$\text{SO}_3$等）

### 3. 物质的制备（以$\text{NaOH}$为例）
*   **① 碱性氧化物与水反应**：$\text{Na}_2\text{O} + \text{H}_2\text{O} \rightarrow 2\text{NaOH}$
*   **② 碱与盐反应**：$\text{Ca(OH)}_2 + \text{Na}_2\text{CO}_3 \rightarrow 2\text{NaOH} + \text{CaCO}_3\downarrow$
*   **③ 氯碱工业**：$2\text{NaCl} + 2\text{H}_2\text{O} \xrightarrow{\text{通电}} 2\text{NaOH} + \text{Cl}_2\uparrow + \text{H}_2\uparrow$

### 4. 制备方案评价标准
*   ① 可能性（反应能否发生）
*   ② 经济性（原料成本、产率）
*   ③ 简约性（操作步骤是否简单）
*   ④ 安全性（是否产生有毒有害物质，操作是否安全）

## 第三章 电解质与非电解质

### 1. 基本概念
*   **电解质**：在水溶液里或熔融状态下，能导电的**化合物**。
    *   实例：$\text{HCl}$、$\text{H}_2\text{SO}_4$、$\text{NaOH}$、$\text{KOH}$、$\text{Ba(OH)}_2$、盐类、水（弱电解质）。
*   **非电解质**：在水溶液里或熔融状态下，不能导电的**化合物**。
    *   实例：蔗糖、酒精、$\text{NH}_3$、$\text{CO}_2$、$\text{SO}_2$等。
*   **导电原因**：物质中存在能自由移动的、带电荷的微粒。
*   *注意：单质和混合物既不是电解质，也不是非电解质。*

### 2. 概念辨析与特例
*   $\text{NH}_3$、$\text{CO}_2$ 溶于水后溶液能导电，但不是它们自身电离，而是生成了$\text{NH}_3\cdot\text{H}_2\text{O}$、$\text{H}_2\text{CO}_3$，因此它们是非电解质。
*   导电能力的影响因素：自由移动离子的浓度、离子所带电荷数。
*   特殊导电物质：金属（自由电子）、石墨（自由电子）、电解质溶液或熔融电解质（自由移动的离子）。
*   电解质与导电的关系：电解质不一定导电（如固态$\text{NaCl}$），导电的不一定是电解质（如金属铜、石墨）。
*   电解质与溶解性的关系：电解质不一定都易溶（如$\text{BaSO}_4$难溶，但熔融状态下导电，是电解质）。

## 第四章 电解质的电离与电离方程式

### 1. 电离
*   **定义**：电解质溶于水或受热熔化时，离解成自由移动离子的过程。
*   电离通常需要水分子或加热的作用。

### 2. 电离方程式的书写
*   **书写原则**：左边写化学式，右边写离子符号；遵循原子守恒和电荷守恒。
*   **强酸、强碱、易溶盐**（强电解质）完全电离，用等号“**=**”。
*   **弱酸、弱碱、水**（弱电解质）部分电离，用可逆符号“**$\rightleftharpoons$**”。
*   **示例**：
    *   $\text{NaCl} = \text{Na}^+ + \text{Cl}^-$
    *   $\text{NaCl(熔融)} = \text{Na}^+ + \text{Cl}^-$
    *   $\text{HCl} = \text{H}^+ + \text{Cl}^-$
    *   酸式盐电离：
        *   强酸酸式盐：$\text{NaHSO}_4 = \text{Na}^+ + \text{H}^+ + \text{SO}_4^{2-}$
        *   弱酸酸式盐：$\text{NaHCO}_3 = \text{Na}^+ + \text{HCO}_3^-$（$\text{HCO}_3^-$ 不拆）
    *   $\text{H}_2\text{SO}_4 = 2\text{H}^+ + \text{SO}_4^{2-}$

### 3. 强电解质与弱电解质
*   **强电解质**：强酸（$\text{HCl}$、$\text{H}_2\text{SO}_4$、$\text{HNO}_3$等）、强碱（$\text{NaOH}$、$\text{KOH}$、$\text{Ba(OH)}_2$等）、绝大多数盐。
*   **弱电解质**：弱酸（$\text{CH}_3\text{COOH}$、$\text{H}_2\text{CO}_3$等）、弱碱（$\text{NH}_3\cdot\text{H}_2\text{O}$等）、水。
