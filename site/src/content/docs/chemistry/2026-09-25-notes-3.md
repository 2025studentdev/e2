# 电解质电离与离子反应

## 第一章 强电解质与弱电解质

### 1. 强电解质
*   **定义**：在水溶液中能**完全电离**的电解质。
*   **电离方程式**：书写时用等号“**=**”（或箭头“→”）。
*   **常见强电解质**：
    *   **强酸**：$\text{HCl}$、$\text{HNO}_3$、$\text{H}_2\text{SO}_4$、$\text{HClO}_4$、$\text{HBr}$、$\text{HI}$。
    *   **强碱**：$\text{NaOH}$、$\text{KOH}$、$\text{Ca(OH)}_2$、$\text{Ba(OH)}_2$。
    *   **绝大多数盐**：$\text{NaCl}$、$\text{AgCl}$、$\text{BaSO}_4$ 等（注：难溶性盐如 $\text{AgCl}$、$\text{BaSO}_4$ 溶解的部分完全电离，故属于强电解质）。

### 2. 弱电解质
*   **定义**：在水溶液中**部分电离**的电解质。
*   **电离方程式**：书写时用可逆符号“**$\rightleftharpoons$**”。
*   **常见弱电解质**：
    *   **弱酸**：$\text{CH}_3\text{COOH}$、$\text{HF}$、$\text{HClO}$、$\text{H}_2\text{S}$、$\text{H}_2\text{CO}_3$、$\text{H}_3\text{PO}_4$。
    *   **弱碱**：$\text{NH}_3\cdot\text{H}_2\text{O}$。
    *   **水**：$\text{H}_2\text{O}$。
*   **电离特点（多元弱酸）**：分步电离，以第一步为主。
    *   示例（碳酸）：$\text{H}_2\text{CO}_3 \rightleftharpoons \text{H}^+ + \text{HCO}_3^-$（主）；$\text{HCO}_3^- \rightleftharpoons \text{H}^+ + \text{CO}_3^{2-}$（次）。
    *   示例（氢硫酸）：$\text{H}_2\text{S} \rightleftharpoons \text{H}^+ + \text{HS}^-$；$\text{HS}^- \rightleftharpoons \text{H}^+ + \text{S}^{2-}$。
    *   示例（醋酸）：$\text{CH}_3\text{COOH} \rightleftharpoons \text{CH}_3\text{COO}^- + \text{H}^+$。

### 3. 电离与水溶液导电性
*   电解质在水溶液中电离出自由移动的离子，使溶液导电。
*   弱电解质（如醋酸）溶液中存在大量未电离的分子，离子浓度较小，导电能力相对较弱。

## 第二章 离子反应与离子方程式

### 1. 离子反应
*   **定义**：有离子参加或生成的反应。
*   **本质**：反应物中某些离子的浓度发生改变。
*   **实例**：$\text{Zn} + 2\text{HCl} = \text{ZnCl}_2 + \text{H}_2\uparrow$（置换反应）

### 2. 离子方程式的书写
*   **定义**：用实际参加反应的离子符号来表示反应的式子。
*   **书写步骤**：写、拆、删、查。
*   **示例**：$\text{Na}_2\text{SO}_4 + \text{BaCl}_2 = 2\text{NaCl} + \text{BaSO}_4\downarrow$
    *   离子方程式：$\text{SO}_4^{2-} + \text{Ba}^{2+} = \text{BaSO}_4\downarrow$
*   **“拆”的原则**：
    *   **必须拆**：强酸、强碱、可溶性盐。
    *   **不能拆**：弱酸、弱碱、难溶物、氧化物、气体、水、单质。
    *   *示例*：$\text{H}_2\text{SO}_4 + 2\text{NaOH} = \text{Na}_2\text{SO}_4 + 2\text{H}_2\text{O}$ 的离子方程式为 $\text{H}^+ + \text{OH}^- = \text{H}_2\text{O}$。

### 3. 离子反应发生的条件
*   **复分解反应类型**：生成**沉淀**、**气体**或**水**。
*   **置换反应类型**：
    *   金属 + 酸 $\rightarrow$ 盐 + $\text{H}_2\uparrow$（需活泼金属）。
    *   金属 + 盐 $\rightarrow$ 新盐 + 新金属（如 $\text{Fe} + \text{CuSO}_4 = \text{FeSO}_4 + \text{Cu}$）。
    *   *特殊注意*：
        *   活泼金属（$\text{K}$、$\text{Ca}$、$\text{Na}$）与盐溶液反应时，先与水反应，不能直接置换出金属。
        *   金属与硝酸反应不生成 $\text{H}_2$（如 $\text{Cu} + \text{HNO}_3$）。

### 4. 离子方程式正误判断“六大”易错点
1.  看是否符合**客观事实**。
2.  看化学式**拆写是否正确**（强酸、强碱、可溶性盐拆；弱酸、弱碱、难溶物、氧化物、气体、水不拆）。
3.  看是否遵循**质量守恒**和**电荷守恒**。
4.  看是否**漏掉**离子反应。
5.  看反应物或产物的**配比**是否正确。
6.  看是否符合**题设条件及要求**（如“过量”、“少量”、“适量”等）。

## 第三章 微溶物的特殊处理

### 微溶物（特指 $\text{Ca(OH)}_2$）
*   **作为生成物**：微溶物**不拆**，写化学式。
*   **作为反应物**：
    *   **石灰水**（稀溶液）：拆成离子形式，即 $\text{Ca}^{2+} + 2\text{OH}^-$。
    *   **石灰乳/石灰浆**（悬浊液）：**不拆**，写化学式 $\text{Ca(OH)}_2$。
