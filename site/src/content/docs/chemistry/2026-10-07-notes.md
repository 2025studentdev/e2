# 离子反应 知识点笔记

## 一、离子反应
1. **定义**：有自由移动离子参加或生成的反应。
2. **实质**：溶液中某些离子浓度发生显著变化，或离子间发生电子转移。
3. **常见类型**
    - 复分解型离子反应：生成沉淀、气体、弱电解质。
    - 氧化还原型离子反应：离子间发生电子转移，如 Fe + Cu²⁺ = Fe²⁺ + Cu。
    - 络合型：如 Fe³⁺ + 3SCN⁻ = Fe(SCN)₃（选修内容）。

## 二、电解质与电离
1. **电解质**：在水溶液里或熔融状态下能导电的化合物。
2. **非电解质**：在水溶液里和熔融状态下都不导电的化合物。
3. **强电解质**：完全电离，如强酸、强碱、大多数盐。
4. **弱电解质**：部分电离，如弱酸、弱碱、水。
5. **电离方程式**
    - 强电解质：NaOH = Na⁺ + OH⁻
    - 弱电解质：CH₃COOH ⇌ CH₃COO⁻ + H⁺

## 三、离子方程式
1. **定义**：用实际参加反应的离子符号表示离子反应的式子。
2. **书写步骤**：写 → 拆 → 删 → 查。
3. **拆写原则**
    - **拆**：强酸、强碱、可溶性盐。
    - **不拆**：弱酸、弱碱、难溶物、氧化物、气体、水、单质。
    - **微溶物**：作反应物且为澄清溶液时拆；作悬浊液或生成物时一般不拆。
    - **酸式酸根**：HCO₃⁻、HSO₃⁻、HS⁻等不拆；HSO₄⁻在水溶液中拆为 H⁺ + SO₄²⁻。
    - **浓硫酸**不拆；浓盐酸、浓硝酸一般拆。
4. **正误判断**
    - 是否符合客观事实。
    - 拆写是否正确。
    - 是否质量守恒、电荷守恒。
    - 是否漏写离子反应。
    - 少量、过量对产物是否有影响。

## 四、离子反应发生的条件
1. **生成沉淀**：如 Ag⁺ + Cl⁻ = AgCl↓，Ba²⁺ + SO₄²⁻ = BaSO₄↓。
2. **生成气体**：如 2H⁺ + CO₃²⁻ = H₂O + CO₂↑。
3. **生成弱电解质**：如 H⁺ + OH⁻ = H₂O，H⁺ + CH₃COO⁻ = CH₃COOH。
4. **发生氧化还原反应**：如 Cl₂ + 2Fe²⁺ = 2Cl⁻ + 2Fe³⁺。
5. **发生双水解**：如 Al³⁺ 与 HCO₃⁻、CO₃²⁻、AlO₂⁻等。

## 五、离子共存
不能大量共存的情况：
1. 生成沉淀：Ag⁺与Cl⁻，Ba²⁺与SO₄²⁻，Ca²⁺与CO₃²⁻等。
2. 生成气体：H⁺与CO₃²⁻、HCO₃⁻、SO₃²⁻、S²⁻等。
3. 生成弱电解质：H⁺与OH⁻、CH₃COO⁻、ClO⁻等；OH⁻与NH₄⁺等。
4. 氧化还原：Fe³⁺与I⁻、S²⁻；MnO₄⁻与Fe²⁺、I⁻等。
5. 双水解：Al³⁺与HCO₃⁻、CO₃²⁻、AlO₂⁻；Fe³⁺与CO₃²⁻、HCO₃⁻等。
6. 隐含条件：
    - 无色溶液排除 Cu²⁺、Fe³⁺、Fe²⁺、MnO₄⁻等有色离子。
    - 酸性条件排除与 H⁺ 反应的离子。
    - 碱性条件排除与 OH⁻ 反应的离子。

## 六、离子反应的意义
1. **揭示反应本质**：如酸碱中和本质是 H⁺ + OH⁻ = H₂O。
2. **表示同一类反应**：一个离子方程式可表示一类反应，如强酸强碱中和。
3. **简化方程式**：删去旁观离子，突出实际参加反应的离子。
4. **判断离子共存**：判断溶液中离子能否大量共存。
5. **用于物质检验**：如 Cl⁻用 Ag⁺检验，SO₄²⁻用 Ba²⁺检验，CO₃²⁻用 H⁺检验。
6. **用于除杂与分离**：如除去 NaCl 中的 Na₂CO₃，可加适量盐酸。
7. **用于生产与环保**：废水处理、硬水软化、物质制备等。
8. **用于定量计算**：根据离子方程式系数比进行相关计算。

## 七、易错提醒
1. 离子方程式两边必须同时满足：原子守恒、电荷守恒。
2. 不是所有反应都能写离子方程式，固体间反应一般不用离子方程式表示。
3. 注意“少量”“过量”对产物的影响。
4. 注意反应先后顺序，如氧化还原中谁先反应。
5. 注意弱电解质、难溶物、气体、水等不能拆。
