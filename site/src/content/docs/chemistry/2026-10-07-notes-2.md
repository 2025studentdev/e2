# 氧化还原反应 知识点笔记

## 一、基本概念

### 1. 定义
**氧化还原反应**：有电子转移（电子的得失或偏移）的化学反应。

- 电子得失：如金属钠与氯气反应，钠失电子，氯得电子。
- 电子偏移：如氢气与氯气反应，共用电子对偏向氯，也属于氧化还原反应。

### 2. 特征
**化合价升降**：反应前后有元素化合价升高，同时有元素化合价降低。

- 判断依据：凡是有元素化合价升降的反应，都是氧化还原反应。
- 化合价升高 → 失电子 → 被氧化 → 发生氧化反应。
- 化合价降低 → 得电子 → 被还原 → 发生还原反应。

### 3. 本质
**电子转移**：包括电子的得失和电子对的偏移。

- 氧化还原反应的本质是电子转移，特征是化合价升降。
- 电子转移总数 = 化合价升高总数 = 化合价降低总数。

### 4. 相关概念对应关系

| 项目 | 还原剂 | 氧化剂 |
|---|---|---|
| 化合价 | 升高 | 降低 |
| 电子 | 失电子 | 得电子 |
| 变化 | 被氧化 | 被还原 |
| 反应 | 发生氧化反应 | 发生还原反应 |
| 性质 | 具有还原性 | 具有氧化性 |
| 产物 | 氧化产物 | 还原产物 |

**口诀**：
- **升失氧，降得还；剂性一致，其他相反。**
- 升价、失电子、被氧化、发生氧化反应、是还原剂、生成氧化产物。
- 降价、得电子、被还原、发生还原反应、是氧化剂、生成还原产物。
- 氧化剂具有氧化性，被还原，生成还原产物。
- 还原剂具有还原性，被氧化，生成氧化产物。

### 5. 常见例子
\[
2Na + Cl_2 = 2NaCl
\]
- Na：0 → +1，失电子，被氧化，是还原剂，NaCl 是氧化产物。
- Cl：0 → -1，得电子，被还原，是氧化剂，NaCl 是还原产物。

注意：同一物质中不同元素可能分别被氧化和被还原；同一元素也可能既被氧化又被还原，如歧化反应。

## 二、电子转移表示方法

### 1. 双线桥
**画法**：
- 从反应物中变价元素指向生成物中同种元素。
- 箭头跨越等号。
- 标“失/得 n e⁻”。
- 标化合价升降、被氧化/被还原。

**示例**：
\[
2Na + Cl_2 = 2NaCl
\]
- Na：0 → +1，失 \(2e^-\)，被氧化。
- Cl：0 → -1，得 \(2e^-\)，被还原。

双线桥表示：
- 从 2Na 指向 2NaCl 中的 Na，标“失 \(2e^-\)，化合价升高，被氧化”。
- 从 Cl₂ 指向 2NaCl 中的 Cl，标“得 \(2e^-\)，化合价降低，被还原”。

### 2. 单线桥
**画法**：
- 从还原剂中失电子元素指向氧化剂中得电子元素。
- 箭头在反应物之间，不跨越等号。
- 只标电子转移总数，不标“得/失”。

**示例**：
\[
2Na + Cl_2 = 2NaCl
\]
单线桥：从 2Na 指向 Cl₂，标“\(2e^-\)”。

### 3. 双线桥与单线桥区别
| 项目 | 双线桥 | 单线桥 |
|---|---|---|
| 箭头 | 反应物 → 生成物 | 还原剂 → 氧化剂 |
| 是否跨等号 | 跨 | 不跨 |
| 标注 | 得失电子、升降、被氧化/被还原 | 只标电子总数 |
| 作用 | 表示同种元素变化 | 表示电子转移方向 |

## 三、氧化还原反应与四种基本反应类型

| 反应类型 | 是否氧化还原 | 说明 |
|---|---|---|
| 置换反应 | 一定是 | 有单质参加和生成，化合价必变 |
| 复分解反应 | 一定不是 | 离子互换，化合价不变 |
| 化合反应 | 可能是 | 有单质参加的一般是，如 \(2Na+Cl_2=2NaCl\) |
| 分解反应 | 可能是 | 有单质生成的一般是，如 \(2KClO_3 \xrightarrow{MnO_2} 2KCl+3O_2↑\) |

注意：
- 有单质参加或生成的反应不一定是氧化还原反应，如 \(3O_2 = 2O_3\)，氧元素化合价均为 0。
- 没有单质参加或生成的反应也可能是氧化还原反应，如 \(NO_2 + H_2O = HNO_3 + NO\)。

## 四、常见元素化合价与变价规律

### 1. 常见元素化合价
| 元素 | 常见化合价 |
|---|---|
| H | +1，金属氢化物中 -1 |
| O | -2，过氧化物中 -1 |
| Cl | -1，0，+1，+3，+5，+7 |
| S | -2，0，+4，+6 |
| N | -3，0，+1，+2，+3，+4，+5 |
| C | -4，0，+2，+4 |
| Fe | 0，+2，+3 |
| Cu | 0，+1，+2 |
| Mn | 0，+2，+4，+6，+7 |

### 2. 价态与氧化性、还原性
- **最高价态**：只有氧化性，如 \(H_2SO_4\) 中 S 为 +6，\(KMnO_4\) 中 Mn 为 +7。
- **最低价态**：只有还原性，如 \(H_2S\) 中 S 为 -2，\(HI\) 中 I 为 -1。
- **中间价态**：既有氧化性又有还原性，如 \(SO_2\) 中 S 为 +4，\(Fe^{2+}\) 中 Fe 为 +2，\(H_2O_2\) 中 O 为 -1。
- 金属单质一般只有还原性；活泼非金属单质一般只有氧化性，如 \(F_2\)、\(Cl_2\)、\(O_2\)。

## 五、氧化剂和还原剂

### 1. 定义
- **氧化剂**：得到电子、化合价降低、被还原、发生还原反应、生成还原产物的物质。
- **还原剂**：失去电子、化合价升高、被氧化、发生氧化反应、生成氧化产物的物质。

### 2. 常见氧化剂
- 活泼非金属单质：\(F_2\)、\(Cl_2\)、\(Br_2\)、\(O_2\)、\(O_3\)。
- 含高价元素的化合物：\(KMnO_4\)、\(MnO_2\)、浓 \(H_2SO_4\)、\(HNO_3\)、\(KClO_3\)、\(K_2Cr_2O_7\)。
- 过氧化物：\(Na_2O_2\)、\(H_2O_2\)。
- 高价金属盐：\(FeCl_3\)、\(CuCl_2\)、\(AgNO_3\)。

### 3. 常见还原剂
- 活泼金属：\(K\)、\(Ca\)、\(Na\)、\(Mg\)、\(Al\)、\(Zn\)、\(Fe\)。
- 某些非金属：\(H_2\)、\(C\)、\(Si\)。
- 低价化合物：\(CO\)、\(SO_2\)、\(H_2S\)、\(HI\)、\(HBr\)、\(NH_3\)、\(FeSO_4\)、\(Na_2SO_3\)。
- 常见离子：\(S^{2-}\)、\(I^-\)、\(Fe^{2+}\)、\(Br^-\)、\(SO_3^{2-}\)。

### 4. 既可作氧化剂又可作还原剂
- 中间价态物质：\(H_2O_2\)、\(SO_2\)、\(Fe^{2+}\)、\(Cl_2\)、\(NO_2\) 等。
- 例如 \(H_2O_2\)：遇强氧化剂时作还原剂，遇强还原剂时作氧化剂。

## 六、氧化性、还原性强弱比较

### 1. 根据反应方程式
对于反应：
\[
氧化剂 + 还原剂 = 还原产物 + 氧化产物
\]
- **氧化性**：氧化剂 > 氧化产物。
- **还原性**：还原剂 > 还原产物。

### 2. 根据金属活动性顺序
\[
K\ Ca\ Na\ Mg\ Al\ Zn\ Fe\ Sn\ Pb\ (H)\ Cu\ Hg\ Ag\ Pt\ Au
\]
- 从左到右，金属还原性减弱。
- 对应阳离子氧化性增强。
- 常见氧化性：\(Fe^{3+} > Cu^{2+} > H^+ > Fe^{2+} > Zn^{2+} > Al^{3+} > Mg^{2+} > Na^+ > Ca^{2+} > K^+\)。

### 3. 根据非金属活动性顺序
\[
F_2 > Cl_2 > Br_2 > I_2 > S
\]
- 氧化性减弱。
- 对应阴离子还原性增强：\(S^{2-} > I^- > Br^- > Cl^- > F^-\)。

### 4. 根据元素周期律
- 同周期从左到右：非金属性增强，氧化性增强；金属性减弱，还原性减弱。
- 同主族从上到下：非金属性减弱，氧化性减弱；金属性增强，还原性增强。

### 5. 根据反应条件
- 越容易反应，氧化性/还原性越强。
- 例如 \(Cl_2\) 与 \(H_2\) 光照爆炸，\(Br_2\) 与 \(H_2\) 加热反应，说明氧化性 \(Cl_2 > Br_2\)。

### 6. 根据产物价态
- 不同氧化剂氧化同一还原剂，使其升价越高，氧化性越强。
- 如 \(Cl_2 + Fe \rightarrow FeCl_3\)，\(S + Fe \rightarrow FeS\)，说明氧化性 \(Cl_2 > S\)。

### 7. 常见顺序表
- **氧化性**：\(F_2 > KMnO_4(H^+) > Cl_2 > Br_2 > Fe^{3+} > I_2 > S\)。
- **还原性**：\(S^{2-} > SO_3^{2-} > I^- > Fe^{2+} > Br^- > Cl^- > F^-\)。
- **常见离子氧化性**：\(Ag^+ > Fe^{3+} > Cu^{2+} > H^+ > Fe^{2+}\)。

## 七、电子守恒计算

### 1. 核心
**氧化剂得电子总数 = 还原剂失电子总数**。

### 2. 公式
\[
n(氧化剂) \times 变价原子个数 \times 化合价降低值
=
n(还原剂) \times 变价原子个数 \times 化合价升高值
\]

### 3. 例题
**题目**：24 mL 0.05 mol/L \(Na_2SO_3\) 溶液恰好与 20 mL 0.02 mol/L \(K_2Cr_2O_7\) 溶液完全反应。已知 \(Na_2SO_3\) 被氧化为 \(Na_2SO_4\)，求 Cr 在还原产物中的化合价。

**解析**：
- \(n(Na_2SO_3) = 0.024 \times 0.05 = 0.0012\ mol\)。
- S：+4 → +6，失 \(2e^-\)，总失电子 \(0.0012 \times 2 = 0.0024\ mol\)。
- \(n(K_2Cr_2O_7) = 0.020 \times 0.02 = 0.0004\ mol\)。
- Cr 原子物质的量：\(0.0004 \times 2 = 0.0008\ mol\)。
- \(K_2Cr_2O_7\) 中 Cr 为 +6，设还原产物中 Cr 为 \(x\)。
- 得电子总数：\(0.0008 \times (6 - x) = 0.0024\)。
- 解得 \(6 - x = 3\)，\(x = +3\)。

**答案**：Cr 在还原产物中为 +3 价。

## 八、氧化还原方程式配平

### 1. 原则
- 电子守恒：得失电子总数相等。
- 质量守恒：反应前后原子个数相等。
- 电荷守恒：离子方程式两边电荷总数相等。

### 2. 步骤
1. 标出反应前后变价元素的化合价。
2. 列出每种元素化合价的升降变化。
3. 求最小公倍数，使得失电子总数相等。
4. 确定氧化剂、还原剂、氧化产物、还原产物的系数。
5. 用观察法配平其他物质。
6. 检查原子守恒、电荷守恒、电子守恒。

### 3. 例题
配平：
\[
Cu + HNO_3(稀) \rightarrow Cu(NO_3)_2 + NO + H_2O
\]
- Cu：0 → +2，失 \(2e^-\)。
- N：+5 → +2，得 \(3e^-\)。
- 最小公倍数 6，所以 Cu 系数 3，NO 系数 2。
- 配平：
  \[
  3Cu + 8HNO_3 = 3Cu(NO_3)_2 + 2NO + 4H_2O
  \]
- 检查：Cu 3，N 8，H 8，O 24，均守恒。

### 4. 缺项配平
- 酸性介质：加 \(H^+\)，生成物加水。
- 碱性介质：加 \(OH^-\)，生成物加水。
- 中性介质：加水。

**示例**：
\[
MnO_4^- + Fe^{2+} + H^+ \rightarrow Mn^{2+} + Fe^{3+} + H_2O
\]
配平：
\[
MnO_4^- + 5Fe^{2+} + 8H^+ = Mn^{2+} + 5Fe^{3+} + 4H_2O
\]

### 5. 离子方程式配平
- 先配电子守恒。
- 再配电荷守恒。
- 最后配原子守恒。

## 九、氧化还原反应的反应顺序

### 1. 一种氧化剂与多种还原剂
- 还原性强的先反应。
- 例如：向 \(FeBr_2\) 溶液中通入 \(Cl_2\)，先氧化 \(Fe^{2+}\)，再氧化 \(Br^-\)。

### 2. 一种还原剂与多种氧化剂
- 氧化性强的先反应。
- 例如：向 \(Fe^{3+}\) 和 \(Cu^{2+}\) 混合溶液中加入铁粉，先与 \(Fe^{3+}\) 反应，再与 \(Cu^{2+}\) 反应。

### 3. 常见顺序
- 还原性：\(I^- > Fe^{2+} > Br^-\)。
- 所以向 \(FeI_2\) 溶液中通入 \(Cl_2\)：先氧化 \(I^-\)，再氧化 \(Fe^{2+}\)。
- 向 \(FeBr_2\) 溶液中通入 \(Cl_2\)：先氧化 \(Fe^{2+}\)，再氧化 \(Br^-\)。
- 向含 \(I^-\)、\(Fe^{2+}\)、\(Br^-\) 的混合溶液中通入 \(Cl_2\)：顺序为 \(I^- > Fe^{2+} > Br^-\)。

## 十、常见氧化还原反应类型

### 1. 置换反应
\[
Zn + CuSO_4 = ZnSO_4 + Cu
\]
- Zn 失电子，Cu²⁺ 得电子。

### 2. 化合反应
\[
2Na + Cl_2 = 2NaCl
\]
- Na 失电子，Cl₂ 得电子。

### 3. 分解反应
\[
2KClO_3 \xrightarrow{MnO_2} 2KCl + 3O_2↑
\]
- Cl 得电子，O 失电子。

### 4. 歧化反应
同一元素一部分化合价升高，一部分降低。
\[
Cl_2 + 2NaOH = NaCl + NaClO + H_2O
\]
- Cl：0 → -1，得电子；0 → +1，失电子。

### 5. 归中反应
同种元素不同价态向中间价态转化，不交叉。
\[
2H_2S + SO_2 = 3S + 2H_2O
\]
- S：-2 → 0；S：+4 → 0。

### 6. 自身氧化还原反应
同一物质中不同元素之间发生氧化还原。
\[
2KClO_3 \xrightarrow{\Delta} 2KCl + 3O_2↑
\]
- Cl 被还原，O 被氧化。

## 十一、常见氧化还原反应举例

1. \(2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-\)
2. \(2I^- + Cl_2 = I_2 + 2Cl^-\)
3. \(2Fe^{3+} + Cu = 2Fe^{2+} + Cu^{2+}\)
4. \(MnO_2 + 4H^+ + 2Cl^- \xrightarrow{\Delta} Mn^{2+} + Cl_2↑ + 2H_2O\)
5. \(2MnO_4^- + 5H_2O_2 + 6H^+ = 2Mn^{2+} + 5O_2↑ + 8H_2O\)
6. \(Cr_2O_7^{2-} + 14H^+ + 6Fe^{2+} = 2Cr^{3+} + 6Fe^{3+} + 7H_2O\)

## 十二、易错点

1. **氧化剂被还原，还原剂被氧化**，不要混淆。
2. 氧化性、还原性强弱与得失电子数目无关，与得失电子难易有关。
3. 有单质参加或生成的反应不一定是氧化还原反应，如 \(3O_2 = 2O_3\)。
4. 歧化反应中同一元素既被氧化又被还原。
5. 归中反应中同种元素不同价态向中间价态转化，不交叉。
6. 注意“少量”“过量”对产物的影响。如铁与稀硝酸反应，铁少量生成 \(Fe^{3+}\)，铁过量生成 \(Fe^{2+}\)。
7. 注意介质对氧化性的影响。如酸性 \(KMnO_4\) 氧化性更强，碱性减弱。
8. 注意电子转移数计算时，要乘以变价原子的个数。
9. 双线桥跨等号，单线桥不跨等号；单线桥只标电子总数。
10. 离子方程式配平必须同时满足电子守恒、电荷守恒、质量守恒。

---

## 十三、氧化还原反应的意义

1. **揭示反应本质**：从电子转移角度认识化学反应。
2. **判断物质性质**：判断氧化性、还原性强弱。
3. **指导物质制备**：如金属冶炼、氯气制备。
4. **用于除杂与分离**：如除去杂质时选择合适氧化剂或还原剂。
5. **用于物质检验**：如 \(Fe^{3+}\) 与 \(I^-\) 反应检验氧化性。
6. **电化学基础**：原电池、电解池都涉及氧化还原反应。
7. **生命活动**：呼吸作用、光合作用均包含氧化还原反应。
8. **工业生产**：合成氨、硫酸制造、硝酸制造等。
9. **环境保护**：废水处理、汽车尾气净化。
10. **定量分析**：氧化还原滴定用于测定物质含量。

---

## 十四、总结口诀

- **升失氧，降得还；剂性一致，其他相反。**
- **升价失电子被氧化，是还原剂，生成氧化产物。**
- **降价得电子被还原，是氧化剂，生成还原产物。**
- **电子守恒：得电子总数 = 失电子总数。**
- **双线桥跨等号，单线桥不跨等号。**
- **氧化性：氧化剂 > 氧化产物；还原性：还原剂 > 还原产物。**
- **还原性顺序：\(S^{2-} > SO_3^{2-} > I^- > Fe^{2+} > Br^- > Cl^-\)。**
- **氧化性顺序：\(F_2 > KMnO_4(H^+) > Cl_2 > Br_2 > Fe^{3+} > I_2 > S\)。**
