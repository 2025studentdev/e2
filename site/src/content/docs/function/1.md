### 一、 函数的单调性

函数的单调性反映了函数值随自变量变化的增减趋势。

#### 核心知识点
1.  **定义法**：对于区间 $D$ 上的任意两个自变量 $x_1, x_2$，若 $x_1 < x_2$，都有 $f(x_1) < f(x_2)$，则 $f(x)$ 在 $D$ 上单调递增；反之则为单调递减。
2.  **导数法**：若 $f'(x) > 0$ 在区间 $D$ 上恒成立，则 $f(x)$ 在 $D$ 上单调递增；若 $f'(x) < 0$ 恒成立，则单调递减。
3.  **复合函数单调性**：遵循“同增异减”原则。即内外层函数单调性相同，复合后为增函数；单调性相反，复合后为减函数。

#### 典型例题
**题目**：求函数 $f(x) = \log_{\frac{1}{2}}(x^2 - 2x - 3)$ 的单调递减区间。

**解析**：
1.  **求定义域**：
    要使函数有意义，真数必须大于0，即 $x^2 - 2x - 3 > 0$。
    解得：$(x-3)(x+1) > 0$，故定义域为 $(-\infty, -1) \cup (3, +\infty)$。

2.  **分析复合结构**：
    令内层函数 $u(x) = x^2 - 2x - 3$，外层函数 $y = \log_{\frac{1}{2}}(u)$。

3.  **判断各层单调性**：
    *   外层函数 $y = \log_{\frac{1}{2}}(u)$ 在 $(0, +\infty)$ 上是**减函数**。
    *   内层函数 $u(x) = (x-1)^2 - 4$ 的对称轴为 $x=1$。
        *   在区间 $(-\infty, -1)$ 上，$u(x)$ 单调递减。
        *   在区间 $(3, +\infty)$ 上，$u(x)$ 单调递增。

4.  **利用“同增异减”法则**：
    要求 $f(x)$ 的单调**递减**区间。由于外层是减函数，我们需要寻找内层函数的**递增**区间（“异减”）。
    结合定义域，内层函数的递增区间为 $(3, +\infty)$。

**答案**：该函数的单调递减区间为 $(3, +\infty)$。

### 二、 函数的奇偶性

函数的奇偶性反映了函数图象关于原点或 $y$ 轴的对称特征。

#### 核心知识点
1.  **前提条件**：函数的定义域必须关于原点对称。
2.  **偶函数**：满足 $f(-x) = f(x)$，图象关于 $y$ 轴对称。
3.  **奇函数**：满足 $f(-x) = -f(x)$，图象关于原点 $(0,0)$ 对称。若奇函数在原点有定义，则必有 $f(0)=0$。

#### 典型例题
**题目**：已知函数 $f(x) = \frac{2^x - 1}{2^x + 1} + a$ 为奇函数，求实数 $a$ 的值。

**解析**：
1.  **方法一：利用定义 $f(-x) = -f(x)$**
    $$f(-x) = \frac{2^{-x} - 1}{2^{-x} + 1} + a = \frac{\frac{1}{2^x} - 1}{\frac{1}{2^x} + 1} + a = \frac{1 - 2^x}{1 + 2^x} + a = -\frac{2^x - 1}{2^x + 1} + a$$
    由 $f(-x) = -f(x)$ 得：
    $$-\frac{2^x - 1}{2^x + 1} + a = -\left( \frac{2^x - 1}{2^x + 1} + a \right) = -\frac{2^x - 1}{2^x + 1} - a$$
    化简得 $a = -a$，即 $2a = 0$，解得 $a = 0$。

2.  **方法二：利用特值法（需检验）**
    因为 $f(x)$ 的定义域为 $\mathbb{R}$，且为奇函数，所以 $f(0) = 0$。
    $$f(0) = \frac{2^0 - 1}{2^0 + 1} + a = \frac{1-1}{1+1} + a = 0 + a = a$$
    所以 $a = 0$。
    检验：当 $a=0$ 时，$f(-x) = -f(x)$ 成立。

**答案**：实数 $a$ 的值为 $0$。

### 三、 抽象函数

抽象函数是指没有给出具体解析式，只给出某些函数关系式或性质的函数。

#### 核心知识点
1.  **赋值法**：通过给变量赋特殊值（如 $0, 1, -1$ 等）来推导函数性质。
2.  **常见模型**：
    *   $f(x+y) = f(x) + f(y) \Rightarrow f(x) = kx$（正比例函数模型）
    *   $f(xy) = f(x) + f(y) \Rightarrow f(x) = \log_a x$（对数函数模型）
    *   $f(x+y) = f(x)f(y) \Rightarrow f(x) = a^x$（指数函数模型）

#### 典型例题
**题目**：已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 满足 $f(x+y) = f(x) + f(y)$，且当 $x > 0$ 时，$f(x) < 0$。
(1) 求证：$f(x)$ 是奇函数；
(2) 判断 $f(x)$ 在 $\mathbb{R}$ 上的单调性并证明。

**解析**：
**(1) 证明奇偶性**：
令 $x = y = 0$，代入原式得 $f(0) = f(0) + f(0)$，解得 $f(0) = 0$。
令 $y = -x$，代入原式得 $f(x - x) = f(x) + f(-x)$，即 $f(0) = f(x) + f(-x)$。
因为 $f(0) = 0$，所以 $f(-x) = -f(x)$。
故 $f(x)$ 是奇函数。

**(2) 判断单调性**：
任取 $x_1, x_2 \in \mathbb{R}$，且 $x_1 < x_2$，则 $x_2 - x_1 > 0$。
由题意知，当 $x > 0$ 时 $f(x) < 0$，所以 $f(x_2 - x_1) < 0$。
考察 $f(x_2) - f(x_1)$：
$$f(x_2) - f(x_1) = f(x_1 + (x_2 - x_1)) - f(x_1)$$
利用已知条件 $f(x+y) = f(x) + f(y)$：
$$= [f(x_1) + f(x_2 - x_1)] - f(x_1) = f(x_2 - x_1)$$
因为 $f(x_2 - x_1) < 0$，所以 $f(x_2) - f(x_1) < 0$，即 $f(x_2) < f(x_1)$。
故 $f(x)$ 在 $\mathbb{R}$ 上是单调递减函数。

**答案**：(1) 证明见解析；(2) $f(x)$ 在 $\mathbb{R}$ 上单调递减。

### 四、 函数的周期性

周期性描述了函数图象重复出现的规律。

#### 核心知识点
1.  **定义**：若存在非零常数 $T$，使得对于定义域内的每一个 $x$，都有 $f(x+T) = f(x)$，则 $f(x)$ 为周期函数，$T$ 为周期。
2.  **重要结论**：
    *   若 $f(x+a) = -f(x)$，则周期 $T = 2a$。
    *   若 $f(x+a) = \frac{1}{f(x)}$，则周期 $T = 2a$。
    *   若 $f(x+a) = f(x-a)$，则周期 $T = 2a$。

#### 典型例题
**题目**：设 $f(x)$ 是定义在 $\mathbb{R}$ 上的奇函数，且图象关于直线 $x=1$ 对称。当 $x \in [0, 1]$ 时，$f(x) = \sqrt{x}$，求 $f(7.5)$ 的值。

**解析**：
1.  **推导周期**：
    *   由 $f(x)$ 是奇函数得：$f(-x) = -f(x)$。
    *   由图象关于直线 $x=1$ 对称得：$f(1+x) = f(1-x)$，即 $f(x) = f(2-x)$。
    *   联立上述两式：$f(2-x) = -f(-x)$。
    *   令 $t = -x$，则 $f(2+t) = -f(t)$。
    *   由此可得 $f(t+4) = f((t+2)+2) = -f(t+2) = -(-f(t)) = f(t)$。
    *   所以，函数 $f(x)$ 的周期 $T = 4$。

2.  **利用周期性转化**：
    $$f(7.5) = f(7.5 - 8) = f(-0.5)$$

3.  **利用奇偶性求解**：
    因为 $f(x)$ 是奇函数，所以 $f(-0.5) = -f(0.5)$。
    因为 $0.5 \in [0, 1]$，代入已知解析式 $f(x) = \sqrt{x}$：
    $$f(0.5) = \sqrt{0.5} = \frac{\sqrt{2}}{2}$$
    所以 $f(7.5) = -\frac{\sqrt{2}}{2}$。

**答案**：$f(7.5)$ 的值为 $-\frac{\sqrt{2}}{2}$。

### 五、 函数的对称性

函数的对称性包括自身的对称（奇偶性、周期性相关）以及两个函数图象之间的对称。

#### 核心知识点
1.  **函数自身的对称性**：
    *   若 $f(a+x) = f(a-x)$，则 $f(x)$ 的图象关于直线 $x=a$ 对称。
    *   若 $f(a+x) = -f(a-x)$，则 $f(x)$ 的图象关于点 $(a, 0)$ 对称。
2.  **两个函数的对称性**：
    *   $y=f(x)$ 与 $y=f(-x)$ 关于 $y$ 轴对称。
    *   $y=f(x)$ 与 $y=-f(x)$ 关于 $x$ 轴对称。
    *   $y=f(x)$ 与 $y=f^{-1}(x)$ 关于直线 $y=x$ 对称。

#### 典型例题
**题目**：若函数 $f(x) = x^2 + mx + n$ 的图象关于直线 $x=1$ 对称，求实数 $m$ 的值，并比较 $f(0), f(1), f(3)$ 的大小。

**解析**：
1.  **求 $m$ 的值**：
    二次函数 $f(x) = ax^2 + bx + c$ 的对称轴公式为 $x = -\frac{b}{2a}$。
    对于 $f(x) = x^2 + mx + n$，对称轴为 $x = -\frac{m}{2}$。
    由题意知对称轴为 $x=1$，所以 $-\frac{m}{2} = 1$，解得 $m = -2$。

2.  **比较大小**：
    此时 $f(x) = x^2 - 2x + n = (x-1)^2 + n - 1$。
    这是一个开口向上的抛物线，对称轴为 $x=1$。
    根据二次函数性质，离对称轴越远的点，函数值越大。
    *   $x=1$ 到对称轴的距离为 $|1-1| = 0$。
    *   $x=0$ 到对称轴的距离为 $|0-1| = 1$。
    *   $x=3$ 到对称轴的距离为 $|3-1| = 2$。

    因为 $0 < 1 < 2$，且开口向上，所以 $f(1) < f(0) < f(3)$。

    *(也可以直接计算验证：$f(1)=n-1$, $f(0)=n$, $f(3)=3+n$)*

**答案**：$m = -2$；大小关系为 $f(1) < f(0) < f(3)$。
