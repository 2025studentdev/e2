title: 自定义域名如何接入Github pages
date: 2026-08-15 12:09:02
---
将自定义域名接入 GitHub Pages，需要完成 **DNS 解析配置**和 **GitHub 仓库设置**两个核心步骤。以下是详细的操作流程。

### 准备工作
*   **拥有一个域名**：且具备修改 DNS 记录的权限。
*   **确定域名类型**：GitHub Pages 支持**顶点域**（如 `example.com`）和**子域名**（如 `blog.example.com`）。

### 第一步：配置 DNS 解析
这是关键的一步，需要在你的域名注册商或 DNS 服务商处操作。

*   **子域名（如 `blog.example.com`）**：添加 **CNAME 记录**。将子域名指向你的 GitHub Pages 默认地址 `用户名.github.io`。
*   **顶点域（如 `example.com`）**：添加 **A 记录**。指向 GitHub Pages 的四个 IP 地址：
    *   `185.199.108.153`
    *   `185.199.109.153`
    *   `185.199.110.153`
    *   `185.199.111.153`

> **提示**：DNS 更改后，生效可能需要**长达 24 小时**，请耐心等待。

### 第二步：在 GitHub 仓库中设置
1.  **进入仓库设置**：在你的 GitHub 仓库页面，点击 **Settings**（设置）。
2.  **找到 Pages 设置**：在左侧边栏的“Code and automation”部分，点击 **Pages**。
3.  **填入自定义域名**：在“Custom domain”下，输入你的完整域名（如 `blog.example.com`），然后点击 **Save**（保存）。
    *   如果你是从分支发布站点，GitHub 会自动在仓库根目录创建一个 `CNAME` 文件。
    *   如果你使用自定义 GitHub Actions 工作流，则**不需要** `CNAME` 文件。

### 第三步：启用 HTTPS（可选但推荐）
保存域名后，等待 GitHub 验证通过并自动配置 SSL 证书。在同一个 Pages 设置页面，勾选 **Enforce HTTPS** 即可强制使用 HTTPS 访问。

### 注意事项
*   **域名唯一性**：一个自定义域名在 GitHub Pages 的所有站点中必须是唯一的。
*   **域名验证**：为提高安全性，建议先在 GitHub 设置中验证域名所有权。
*   **故障排查**：如果配置后无法访问，请检查 DNS 记录是否正确、`CNAME` 文件内容是否准确。
